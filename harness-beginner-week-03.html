小白版第3周：接上 DeepSeek API，第一次让模型回答

这周只做一件事：让 DSH 真正回答一句话

上周装好工作台，这周给它接上模型。API 可以先理解成软件调用模型的通道；API Key 是使用这个通道的秘密凭证。 它像一把会影响账户用量的钥匙，不是普通验证码，不能给别人。

想先不付费？可以读完本周，继续做第5周的本地程序练习；但 DSH 的在线任务要等你完成真实接入后才能做，不能把阅读当接入成功。

第15天：确认自己进入官方平台

在浏览器输入 https://platform.deepseek.com/，按官方流程注册或登录。不要通过陌生人的代开账号链接进入。

平台可能让你验证邮箱或其他信息，按当期页面要求操作。遇验证码、地区或账号限制，不要购买共享账号绕过。

完成标志： 你知道自己登录的是 API 平台，不是只和 DeepSeek 聊天的普通页面。找不到时请助手解释官方页面用途，不让它代收你的登录信息。

第16天：先看价格，再决定是否继续

打开官方模型与价格页，再看账户余额／用量页面。你现在不用背价格表，只知道模型不同、输入输出长度不同，费用可能不同。

Token 是模型计算文字长度的单位，和汉字数量不总是相等。不要把本课短问候的费用当成所有任务的费用保证。

在 learn.txt 写一个自己的最高可接受支出。平台若提供提醒或限额可开启；没有就用小额预算、少量请求和人工检查。本课不要求某个充值金额，也不替你决定付款。

第17天：创建只供学习的 Key

在平台找到 API Keys 或 API 密钥入口，选择创建新密钥；如果能起名字，就叫 learning-dsh，方便以后识别。

创建后可能只显示一次完整内容。按官方建议用可信密码管理器安全保存，或直接填入 DSH；不要存进 learn.txt、聊天、截图、邮箱草稿或公开网盘。不要为了让助手看懂，给它完整 Key。

完成标志： 你知道密钥在哪创建、该填在哪里，也知道泄露后要去平台撤销。没有完成安全保存就先停，不要到处复制。

第18天：在 DSH 的模型设置里配置

  1. 打开 DSH，找设置中的模型／提供方入口，英文可能是 Models 或 Providers。
  2. 选择官方 DeepSeek 提供方，把自己的 Key 填到对应密钥框，不是聊天输入框。
  3. 按当前界面保存，并选择账户可用的模型。模型名以当前平台和 DSH 实际可用项为准，不照抄旧教程名称。

如果要求服务地址，只在官方 DeepSeek 接口场景对照官方首次调用说明核对，通常是 https://api.deepseek.com。不要为了解决问题把 Key 填到陌生代理网站。

各版本界面可能不同，可查DSH 官方模型适配器说明。找不到对应入口就先求助，别在未知文件里乱改设置。

第19天：只发一句最短的练习

在 DSH 新建一段对话，确认正在使用刚配置的 DeepSeek 模型，再发送：

请只用一句中文向初学者问好。
这一轮不要读文件、运行命令或调用任何工具。

应该看到： 一句实际返回的问候。不是教程写的固定句子，文字不同很正常。发送一次后等待，不连续点击十次；失败也可能需要核对是否已有用量。

第20天：认识三种常见失败

  • 提示 401 或鉴权失败：先检查 Key 是否有效、是否填对入口，不把 Key 发给人检查。
  • 提示余额、权限或模型错误：查看平台实际说明、余额与可用模型，不直接重装 DSH。
  • 一直转圈或网络超时：先停止，检查网络和官方状态。超时不一定意味着服务端没处理，别不停重试。

把错误文字中不含秘密的部分记下来。如果今天已经成功，不需要故意浪费钱制造这些错误。

第21天：复盘与完成标志

正常退出后再打开 DSH，确认模型配置是否保留。愿意且预算允许才再做一次短请求，不要求为了打卡重复付费。

在 learn.txt 写：实际模型名、第一次成功的日期、有没有查看用量、遇到的问题。不写 Key。

本周过关： 知道 API 和 Key 是什么；在 DSH 真正收到回复；知道花费在哪里查看；知道 Key 泄露要撤销并重新创建，而不是只删聊天。

给面试打一点基础

练习用自己的话回答：DSH 界面能打开，为什么不代表模型已经接通？因为软件启动和模型服务鉴权、余额、网络是不同环节。现在能说清这一句就够了。
