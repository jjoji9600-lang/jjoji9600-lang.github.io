小白版第1周：先学会找到、打开和保存文件

这周只做一件事：能找到自己的练习文件

不用写代码、不用注册 GitHub、不用买 API。先把文件准备好。你会经常看到文件夹、解压、保存几个词，我们就在实际操作中认识它们。

文件夹像抽屉，文件像抽屉里的纸。文件名最后的 .txt、.csv、.py 是扩展名，帮助电脑判断怎样打开。现在只打开 .txt，其他文件先不动。

第1天：建立自己的学习抽屉

  1. 按键盘上的 Win+E：按住带 Windows 标志的键，再按 E。会打开文件资源管理器，也就是平常找文件的窗口。
  2. 在左侧找到文档。如果你的电脑位置不同，也可以选一个你有权限保存文件的位置，不用强求放在 C盘。
  3. 在空白处右键，选择新建 → 文件夹，输入 AI-Learn，按回车。

完成标志： 能看到 AI-Learn 文件夹，双击可以进去。今天只要做到这里就够了。

找不到文档？问办公助手：我用 Windows，我已打开文件资源管理器，左侧是这些项目……下一步点哪里？不要把整个个人文件列表截图公开。

第2天：下载并找到压缩包

  1. 在浏览器打开这个下载链接。文件名应为 ai-start.zip。
  2. 下载完成后，在浏览器右上角找下载箭头，或按 Ctrl+J 打开下载记录。
  3. 找到 ai-start.zip，选择在文件夹中显示，名称也可能是显示文件位置。

应该看到： 一个名为 ai-start.zip 的文件。zip 就是把多个文件打包到一起的压缩包，先不要在里面直接做练习。

如果浏览器问保存到哪里，选择刚建的 AI-Learn。已经存到下载也没关系：选中文件按 Ctrl+C，再进入 AI-Learn 按 Ctrl+V。

第3天：解压，不是在压缩包里直接做

  1. 在文件资源管理器中右键 ai-start.zip，选择全部解压缩或解压全部。
  2. 把目标位置选在 AI-Learn 里面，点击解压。不同 Windows 版本窗口略有区别。
  3. 打开解压后的文件夹，继续进入，直到同一个窗口里能看到 learn.txt、requests.txt、report.py。

完成标志： 当前窗口里能直接看到这三个文件，而且地址栏不是以 .zip 结尾。这个文件夹叫你的练习目录，后面我们就从这里操作。

如果出现 ai-start 里面还有一个 ai-start，不要着急重下：进去一层，找到三个文件即可。后面说打开练习目录，就是打开这一层。

第4天：学会双击打开和保存

  1. 双击 learn.txt。一般会由记事本打开；如果问用什么程序，选择记事本。
  2. 在日期后写今天日期，在今天想完成什么后写：我想学会用 DSH 读取文件。
  3. 按 Ctrl+S 保存，关掉，再双击打开。

完成标志： 刚才输入的文字还在。关窗口不一定自动保存，所以养成 Ctrl+S 的习惯。

现在不要双击 report.py。它是以后才用的程序，双击后窗口一闪而过很正常，不代表你已经运行成功。

第5天：看懂今天的练习材料

双击 requests.txt，逐行读五条求助。它们都是编造的，不是公司真实工单。自己数一遍：几条已完成？几条待处理？把分钟相加是多少？

答案是 5条、3条、2条、60分钟。先会人工核对，以后才能判断 AI 有没有说错。今天不要求用 Excel，也不要求打开 .csv。

完成标志： 不看答案能说出四个数。把结果记到 learn.txt，不用另建复杂笔记系统。

第6天：让文件名显示完整

Windows 有时隐藏文件扩展名，容易把 xxx.txt 存成 xxx.txt.txt。

  • Windows 11：文件资源管理器上方查看 → 显示 → 文件扩展名。
  • Windows 10：上方查看选项卡，勾选文件扩展名。

菜单不同就搜索 Windows 官方关于显示文件扩展名的帮助，不随意更改系统设置。打开后看看 learn.txt 的完整名字；不需要给任何文件改后缀。

再练习复制：选中 requests.txt，按 Ctrl+C，再按 Ctrl+V，会得到一个副本。这个副本可以改，原文件先保留。

第7天：不看教程，再做一遍

关闭所有文件窗口，从文档找到 AI-Learn，再找到练习目录；打开 learn.txt，补一句本周我已经学会……并保存。最后打开 requests.txt，说出四项答案。

本周过关条件： 你知道下载文件在哪、能进入解压后的目录、能打开和保存记事本、知道 .txt 和 .py 不是一回事。做不到哪项就再练一次，不要急着安装一堆软件。

可以问学习助手的一句话

我已经下载 ai-start.zip，但不知道现在是不是在解压后的文件夹。
请先问我窗口地址栏显示什么，再只给我一个检查方法。

这和未来工作有什么关系？

AI 操作错目录，就可能读不到输入或改错文件。先会找到文件，不是浪费时间，而是在建立最基础的工作边界。
