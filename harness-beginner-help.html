小白求助页：文件找不到、命令不会输、GitHub看不懂怎么办

2026-11-14·小白十二周教程·零基础DeepSeek HarnessAI入门

回到小白课程目录

先停一下，不用一出错就重装软件。多数入门问题可以先确认三件事：我在哪个窗口、现在在哪个文件夹、刚才实际做了什么。

1. 这段话到底输入到哪里？

教程让你做什么 应该在哪操作
给 DSH 一段任务要求 DSH 的对话输入框
请办公助手解释术语 WorkBuddy／千问办公的聊天框
输入 powershell 打开终端 Windows 文件资源管理器的地址栏
运行 python report.py 已打开的 PowerShell 终端
修改 learn.txt 用记事本打开的文件里，改完 Ctrl+S
上传项目 浏览器里的自己 GitHub 仓库页面
填 API Key 官方平台或 DSH 密钥设置框；第9周可在本地程序的隐藏输入处

同一段文字放错地方，电脑就不知道你的意思。 不要把 python 命令发给办公助手后，以为程序已经在自己的电脑运行。

2. 下载、解压和安装有什么区别？

下载是把网上文件拿到电脑；解压是把打包的多个文件拆出来；安装是让软件准备好运行。课程练习包是解压，DSH／Python 软件按官方说明安装，二者不是一回事。

不知道文件下载在哪：在浏览器按 Ctrl+J，找到文件，选择在文件夹中显示。不知道有没有解压：进入后能直接看到 learn.txt、requests.txt、report.py，而且地址栏不在 .zip 里。

3. 为什么文件名和教程不一样？

先在 Windows 文件资源管理器开启显示文件扩展名。可能是 learn.txt 被隐藏为 learn，也可能保存成了 learn.txt.txt。

.txt 通常是普通文本，.csv 是表格文本，.py 是 Python 程序，.html 是网页，.zip 是压缩包。不要为了能打开就随便改后缀；应该选择合适的打开方式。

4. 终端里出现英文，是不是坏了？

先读最后几行，再结合刚才的操作。几种常见意思：

提示 先做什么
Python 3.x.x 版本检查成功，确认是3.10或更新
无法识别 python／not recognized 检查安装，重开终端，可先试 py --version
can't open file／找不到文件 用 dir 看当前目录有没有 report.py
Ran 6 tests 和 OK 六项检查通过
Ran 0 tests 没找到检查，不算测试全通过
FAILED／ERROR 有检查没通过，保留错误信息，先找原因
新的 PS ... > 提示符出现 程序通常已结束，可输入下一条命令

如果程序正在问是否继续，它在等你的回答，不是在等另一条命令。想取消本课程序可优先按其取消说明；必要时 Ctrl+C 中止当前前台运行，但注意中止不代表服务端请求一定没执行。

5. AI说完成，为什么我找不到结果？

回到练习目录按 F5。检查文件名、输出位置与执行记录。有可能它只在聊天里给了一段示例，根本没写文件；也可能写到别的目录。

这就是为什么每次都要确认真实文件，不能只信一句完成。旧 weekly.txt 存在也不代表刚才那次成功，要看本轮终端提示与修改时间。

6. API失败时先做什么？

先停止连续点击，记下无秘密的错误信息，检查官方账户、余额、模型与网络。不要把完整 Key 发给人验证，也不要为了排错关闭所有安全功能。

Key 已经泄露：到官方平台撤销，再创建新 Key，重新配置必要软件。删除聊天、网页或文件只能减少继续传播，不能让已经泄露的 Key 自动失效。

7. GitHub英文太多，看不懂

英文 在本课里先理解成
Sign up / Sign in 注册 / 登录
Repository 项目仓库，类似网上项目文件夹
README 项目说明首页
Add file / Upload files 添加文件 / 上传文件
Commit changes 保存这一版修改，并留下记录
Public / Private 公开 / 私有
Settings 设置，要分清仓库设置和账号设置
Pages / Visit site 网页发布功能 / 访问网站
Releases / Assets 软件发布版本 / 该版本的下载文件

不要为了下载公开软件就先学 Fork、Pull Request 或 Git 命令；本课程用不到的按钮，可以暂时不点。

8. 这样求助，别人更容易帮你

复制下面这张卡，填写自己知道的部分，不知道就写不知道：

我在第几周、第几天：
电脑系统：Windows／Mac，版本不知道也可以先写不知道。
使用软件和版本：
我现在在哪个窗口：浏览器／文件资源管理器／记事本／DSH／终端。
我刚才点了什么、输入了什么：
我希望看到什么：
我实际看到了什么：
我已经尝试过什么：
请先用日常语言解释，只给我下一步，不要一次给十条命令。

截图前遮掉账号、邮箱、Key、真实业务数据和个人路径。错误文字可以复制无秘密的几行，不必上传整段终端历史。

9. 我是不是学得太慢？

如果今天学会了找到文件，明天学会了运行一条命令，就是进步。十二周是路线，不是倒计时。不会的地方回去练，远比把所有页面翻完却没有真实做过更有用。
