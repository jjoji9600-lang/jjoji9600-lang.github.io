## 本周目标

不急着接复杂业务。先理解模型、API、Agent、Harness 的分工，准备一个不会暴露个人文件的实验环境。办公 AI 仅用来解释术语与检查笔记，不作为项目运行环境。

本周交付：docs/environment.md、docs/task-card.md、docs/progress.md。需要一台可以安装软件、能访问官方文档的电脑。没有安装权限先向管理员申请，不绕过设备管理。

## 必须理解的五个概念

- 模型：根据输入生成文本或工具调用意图，不直接拥有你电脑的能力。
- API：你的程序与模型服务通信的接口，需要鉴权且可能计费。
- 工具：真正读取文件、运行命令、计算或访问服务的程序。
- Agent：在反馈中选择下一步行动的模型驱动流程。
- Harness：组织模型、工具、会话、上下文、权限、执行与观测的运行系统。

DSH 是具体产品，Harness 是更广泛的工程概念。能解释二者区别，比背一份启动命令重要。

## 跟做：检查基础环境

在解压后的 harness-lab 目录打开终端，逐条运行：

```powershell
pwd
python --version
git --version
python -m unittest discover -s tests -v
python -m src.report --dry-run
```

预期：16 个测试通过；dry-run 输出 total=12、closed=8、minutes=360 和三个部门各 4。不要求本周读懂所有代码，只需知道真实结果来自命令执行，而不是 AI 口述。

如果 python 无法识别，先检查官方安装是否完成、是否重开终端；Windows 可试 py --version，并在后续命令中使用对应可用入口。macOS／Linux 常用 python3。不要随意下载名为修复工具的程序。

## 写一张能执行的任务卡

```text
目标：从模拟 CSV 生成可核对周报，不修改原始数据。
输入：data/tickets.csv。
输出：output/weekly.md。
数字：用确定性程序计算；分类以后由 API 辅助。
允许：读取 data、需求文档，写入 output。
禁止：读取凭证、外发、改业务系统、安装未知依赖。
验收：四项统计与人工真值一致；每个动作有证据。
停止：数据异常、权限不足、费用超预算时暂停。
```

这只是需求约束，不是实际权限隔离。以后要用工具权限、路径校验与隔离环境落实。

## 工作场景与面试题

场景：主管要求做全自动工单助手。你不能直接承诺全自动，应先问数据范围、动作影响、错误成本和审批要求。

1. 模型为什么不能直接等同于 Agent？答题要点：工具、反馈循环、状态与执行环境。
2. Harness 工程师和提示词使用者有什么区别？要点：执行、验证、安全、恢复、评测。
3. 总数统计为何不交给模型？要点：确定性、可测试、可追溯，模型用于必要的语义判断。

## 验收与排错

能运行上述两条 Python 命令；能解释五个概念；任务卡六项齐全；没有泄露隐私。未通过就用两天补齐，不急着进入 API。

CSV 乱码时按 UTF-8 导入；文件名出现 .md.txt 时开启扩展名显示；测试失败先确认位于项目根目录，别立刻修改测试来让结果变绿。
