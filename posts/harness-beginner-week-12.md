## 这周只做一件事：讲清自己真正做过什么

学完十二周，不代表突然变成专业工程师，也不保证拿到工作。但你应该从不会找文件，进步到能完成一次有边界、有结果检查的小练习。

现在整理证据，不堆高深词。面试官问到 DSH、API、文件、权限或一次报错时，你要能用自己的操作回答。

## 第78天：列出真实完成清单

打开 learn.txt，逐项填已完成／还没完成：能找练习目录；能启动 DSH；是否真实连接 DeepSeek API；是否实际读写文件；能否运行 report.py；六个检查是否通过；是否真正加载 Skill；是否有 GitHub 页面。

没有做过就写没做过。只读过 Skill 介绍，不等于安装成功；借助参考程序，不等于独立开发完整平台。

## 第79天：做五个小检查

恢复原始模拟数据，按以下五项手工核验：

1. DSH 读取的是你指定文件，而不是猜内容。
2. 程序输出5、3、2、60，与人工答案一致。
3. 将10改20后总分钟变70，改回后恢复60。
4. 错误输入会停，旧报告不被当成新结果。
5. 没有未经批准读秘密、删文件或发出去。

暂时不能做哪项就标记待验证。这里只是五个入门检查，不是生产安全认证，不给自己包装成100%可靠。

## 第80天：准备一个三分钟演示

先写一个小提纲，再自己讲一遍：

```text
我做这个练习想解决什么：整理五条模拟求助。
我用了什么：DSH负责组织操作，程序算数，模型提供语言能力。
我实际做了什么：只说真正完成的步骤。
我怎么核对：人工答案、实际文件、运行结果与测试。
我遇到一次什么错误：怎么发现、怎么恢复。
我还有什么不会：真实说出下一步。
```

演示前隐藏账号、路径隐私与所有密钥。以前录好的真实结果可以展示，但要说这是录制记录；离线模拟不能装成实时在线调用。

## 第81天：给自己做一次基础问答

不看稿回答五题，卡住再回看对应周：

- DSH 和 DeepSeek 模型是一回事吗？不是，前者是组织模型与工具工作的环境。
- API Key 能发给辅导助手吗？不能，它是秘密凭证。
- AI 说保存成功，怎么确认？到实际位置打开文件，并看执行记录。
- 六个测试通过，是否保证永不出错？不保证，检查范围有限。
- GitHub 网页能直接运行本地 Python 吗？GitHub Pages 是静态展示，不是这个程序的运行服务。

不必背标准话术，能结合自己的文件解释更好。

## 第82天：把作品首页改诚实、改清楚

在 GitHub 的 README 里写：这个项目做什么、怎么运行、自己改了哪里、参考了什么、哪些还没做。只需一页。

可用下面这个简短模板，逐项替换：

```text
这是我的 DSH 入门练习，材料来自课程参考包。
我实际完成了：填写可验证的操作。
我自己修改了：填写真实改动，没有就如实写。
运行方式：安装Python，在本目录运行 python report.py。
检查方式：python -m unittest -v，并人工核对模拟数据。
仍未完成：填写真实短板。
```

模板不是简历业绩。不要把课程已有的六个检查说成自己设计了六个测试。

## 第83天：先看岗位，再判断是否适合投递

找三份真实的初级 AI 应用／Agent 相关招聘描述，不只搜索 Harness 工程师。把要求分成我能展示、我只是听过、我完全没学过三类。

若要求独立写 Python 服务、数据库、部署、并发和评测，而你还只能运行参考程序，那就先补基础，或考虑更贴近实际能力的实习／助理方向；不要把十二周标签当录用保证。

可以开始小规模尝试，但简历只写真实经历：基于 DSH 完成模拟求助分析练习，使用参考程序核对数据，记录权限和失败处理。没有在线 API 证据，就不写已完成 API 集成。

## 第84天：决定下一步，不再盲学一堆工具

接下来四周可这样补：第一周多练 Python 变量、判断、函数；第二周给自己的小改动写检查；第三周学习 Git 的保存修改、查看差异与恢复；第四周做一个不看课程也能从零完成的小功能。

如果 DSH 或 API 还没接通，先补齐那一步；如果 Skill 仍未加载，按版本说明完成发现和加载验证。不要为了追热门再装十个新工具。

**这门课真正的毕业标准：** 你知道自己在哪操作、做了什么、为什么成功或失败，以及哪些部分还不懂。能诚实复现一个小任务，比背一串工程术语更接近真正入门。

## 给未来的自己

不会 GitHub、终端和代码并不是不能开始的理由。只是起点不同，需要把大步骤拆小。以后再读[工程版教程](harness-12-weeks.html)，你会知道那些词对应的是自己做过的哪件事，而不再只是陌生名词。
