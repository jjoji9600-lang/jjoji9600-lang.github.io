小白版第2周：安装 DeepSeek Harness，先认清界面

这周只做一件事：把 DSH 装好，认清自己在哪工作

DSH 是 DeepSeek Harness 的简称。本周优先用官方桌面版，不要求先安装 Node.js、不要求输入 npm 命令。桌面版可能是预览版，菜单会变；看不见相同按钮，不代表你做错了。

先别急着付费或填写 Key。 没接模型时可能暂时不能聊天，这是第3周才解决的事情。

第8天：第一次见 GitHub，但只把它当下载网页

打开 DSH 官方项目。现在不需要账号，不用点 Star、Fork，也不用懂仓库。

在页面找到 Releases，它表示发布的软件版本。找不到就直接打开版本下载页。你要做的是下载发布的软件，不是下载源代码。

完成标志： 打开某个官方版本的详情，能看到版本号和 Assets。Assets 是下载文件列表；如果折叠，点一下展开。

第9天：只下载适合自己系统的安装包

先按 Win+I 打开设置，找系统 → 关于，查看系统类型。多数常见 Windows 电脑是 x64，但不要凭猜测；ARM 电脑需选相应版本。

回到官方 Assets：按发布说明选择 Windows 对应的桌面安装文件。通常是 .exe 等安装格式，不要把 Source code.zip 当软件安装包。文件名以当期发布为准，本课不编造固定安装文件名。

看不懂列表？把版本页链接和你的系统类型给学习助手，要求它解释每个文件名，确认来源仍是官方项目。不要下载搜索广告、陌生镜像或来历不明的安装器。

第10天：安装并打开

在浏览器下载记录找到安装文件，先核对来源，再双击。按安装器的正式提示完成安装，然后从开始菜单搜索 DeepSeek Harness 并打开。

如果出现未知来源或安全软件拦截，先停下来，核对官方说明、文件与发布者；不要为了跟课直接关闭杀毒或跳过所有警告。若当期没有适合你系统的桌面包，先看官方安装说明并求助，本周不强迫小白临时走复杂编译路线。

完成标志： 能打开软件，看到主界面或首次设置界面。暂时提示配置模型也算正常。

第11天：认识三个地方，不求一次看懂全部

在你实际版本中找到：对话区域、设置入口、选择／打开工作文件夹的入口。名称可能是工作区、文件夹、Workspace 或 Open Folder。

工作文件夹就是这次允许 AI 帮你处理材料的位置。选择第1周那个直接包含 learn.txt、requests.txt 的练习目录，不是整个文档、下载目录或桌面。

如果界面找不到入口，记录版本并向助手描述；不要随便给软件授权整个磁盘来解决。

第12天：把当前设置记下来

打开 learn.txt，写三行：

我安装的 DSH 版本：填写软件实际显示的版本。
我的练习目录：填写自己找到的位置。
我目前能看到：设置／对话／文件夹等实际界面。

这不是写代码，只是笔记。版本通常能在关于页面、窗口信息或官方说明里找到；找不到就写暂未找到，不猜一个。

第13天：学会退出和重新打开

正常关闭软件，再从开始菜单打开，检查工作目录是否还是练习目录。不是就重新选择。先不要尝试远程控制、公开网址、定时任务或社区插件。

没有模型配置时，不用反复点发送来试探；下一周才做 API 接入。若软件自带其他模型或订阅入口，也不要为绕过本课步骤随意开通。

完成标志： 不靠安装器，能自己重新打开软件，并确认当前工作目录。

第14天：本周检查

请自己回答：我下载的是官方安装包还是源代码？当前软件操作哪个文件夹？我知道设置在哪里吗？我的电脑是什么系统类型？

把还不确定的地方记下来。做到安装、打开、定位工作目录，就可以进入下一周，不要求你此时懂 Profile 或插件。

卡住时怎么问？

我用 Windows，系统类型是……，DSH 版本是……。
我现在停在这个界面，想找到选择工作文件夹的入口。
请先确认我应该找哪个位置，不要编造固定按钮。

一个小问题

DSH 是大模型本身吗？不是。它是帮助模型调用工具、处理文件和执行任务的软件环境。模型怎么接进来，下周再学。
