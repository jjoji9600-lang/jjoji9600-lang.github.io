小白版第5周：第一次打开终端，运行一个小程序

这周只做一件事：让电脑用程序算出正确数字

终端是一个输入文字指令的窗口；命令是你告诉电脑要做什么的一行文字。Python 是运行 .py 小程序的软件。你现在只需要会运行，不要求立刻会写。

本周只装 Python，不装 Git、Node、数据库。练习的 report.py 不联网、不调用付费 API，只读取 requests.csv，写 weekly.txt。

第29天：从官方网站安装 Python

打开 python.org/downloads，按官网 Windows 安装说明选择适合系统的版本，本练习需要 Python 3.10 或更新。

下载方式会变化：如果是传统安装器且有 Add python.exe to PATH 选项，可按官方说明勾选；如果是安装管理器，就按该方式的官方步骤完成。不要到第三方下载站找精简版。

安装完成后关闭旧终端，再开新的。系统要求管理员权限而你没有时先询问管理员，不绕过公司策略。

第30天：第一次打开终端

  1. 按 Win+E，进入能直接看到 report.py、requests.csv 的练习目录。
  2. 点击窗口上方地址栏，原来的文件夹路径会被选中。
  3. 输入下面这一个单词，再按回车：
powershell

应该弹出一个可以输入文字的窗口，常见开头类似 PS C:\某个文件夹>。颜色可能不同，正常。地址栏输入 powershell 是打开终端的动作，不是要把文件夹改名。

完成标志： 窗口里有一行提示符和闪动光标。不要把示例中的 PS 或 > 也输入。

第31天：只运行一条检查命令

在终端窗口光标处输入，按回车：

python --version

应该看到 Python 3.x.x。数字可能和教程不同，只需满足 3.10+。

如果显示无法识别，先尝试 py --version。若 py 能用，后面每条命令开头的 python 都改为 py。两者都不行，回到官方安装说明检查并重开终端。若跳出应用商店，说明当前入口没有找到可用 Python，不要误以为安装完成。

看不懂错误先停，不运行网上让你改注册表、关闭安全策略的一串命令。

第32天：确认自己站在正确目录

在终端输入：

dir

dir 的意思是列出当前文件夹中的内容。输出应能找到 report.py 和 requests.csv；如果找不到，关闭这个终端，回到正确的文件资源管理器目录，再按第30天的方法打开。

这比先背 cd 命令更简单。记住：运行程序前先确定自己在哪个文件夹。

第33天：第一次运行小程序

确认目录正确后输入：

python report.py

若前面你选择 py，这里就输入 py report.py。不要输入三行反引号，也不要把本页解释文字一起复制。

应该看到： 成功：已经生成 weekly.txt，下面显示总条数5、已完成3、待处理2、总分钟60。

回到文件资源管理器，按 F5，双击 weekly.txt。里面应该有相同数字。终端和实际文件都检查，才算完成。

第34天：让 DSH 解释，但先不改代码

回到 DSH，确认还是这个练习目录，发送：

请只读取 report.py，不修改任何文件。
我是第一次接触代码。先只解释这个程序读哪个文件、写哪个文件、会不会联网。
不要逐行讲所有语法，不要让我先安装额外依赖。
我回答后，你再解释下一个问题。

你要能回答：输入是 requests.csv，输出是 weekly.txt，程序本身不联网。这里的输入／输出，就是拿什么来处理、最后生成什么。

第35天：不看教程完成一次

从打开练习目录开始，重新打开终端，确认 Python 可用、确认目录，再运行 report.py，打开 weekly.txt 核对四个数。把真实结果写进 learn.txt。

本周过关： 能自己打开终端，知道命令在哪里输入，能运行程序并找到产物。暂时不会写函数没有关系。

最常见的三个坑

  • can't open file 或找不到文件：多数先查当前目录，不是要重装 Python。
  • 窗口一闪而过：通常是双击 .py；按本课从终端运行才能看见结果。
  • 文件还是昨天的：本次命令可能失败。看终端有没有成功提示，并查看 weekly.txt 的修改时间；旧文件存在不代表本次成功。

下一周我们才用这个小程序练习检查和修改，不要求今天就把整份代码背下来。
