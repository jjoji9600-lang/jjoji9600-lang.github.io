完全零基础也能跟：DeepSeek Harness 十二周小白教程

2026-11-14·小白十二周教程·零基础DeepSeek HarnessAI入门

你不需要先会 GitHub，不需要会编程，也不用先理解一串英文缩写。如果你会开电脑、打开浏览器，我们就从这里开始。

上一版更像已经懂一点技术的人用的学习清单。这一版换一种写法：告诉你在哪里操作、输入什么、看到什么算成功，卡住时怎么退回来。 原来的工程版仍然保留，现在不需要先读它。

先记住三句话

  1. WorkBuddy 或千问办公是你的辅导老师：看不懂时请它解释，不要求它替你做复杂项目。
  2. DeepSeek Harness 是主要练习的软件，DeepSeek API 是它连接的模型服务。 后面我们简称 DSH，但第一次遇见英文不必背。
  3. GitHub 是后面才用来展示作品的网站，前九周不要求注册 GitHub，更不需要先学 Git 命令。

可以粗略想成：DSH 是工作台，DeepSeek 模型是帮你想办法的助手，API 是连接到助手的通道。比喻只帮助入门；工作台还要管理工具、文件、权限和执行过程，后面会亲眼看到。

这门课怎么安排？

每周安排七个小任务，每天约 30—60 分钟，安装和排错可能更久。一周做不完就用两周。不要因为教程写了十二周，就逼自己按日期追赶。

主要演示 Windows 10／11。Mac 用户可以读相同的概念，但不能照抄 Windows 的安装包和菜单；安装与终端步骤请对照官方对应系统说明，必要时带上系统信息求助。本课不假装各系统界面完全一样。

开始前，不要花冤枉钱

浏览教程、下载练习包、前期整理文件和后期使用 GitHub 基础功能，都不要求购买付费套餐。模型 API 通常另行计费，不能把办公软件会员、DeepSeek 聊天会员和 API 余额当作一回事。

第3周才决定是否使用付费 API。先查官方当期价格与余额，定一个你能接受的上限，超出就停。不要为了跟课购买高价套餐或陌生人的代充服务。

我们会完成什么？

用五条虚构的求助记录做一个小练习：让 DSH 找到文件、读懂要求、调用小程序算数、写出一份周报，再检查有没有算错。随后认识 API、Skill、错误处理，最后把自己的学习成果展示到 GitHub。

这不是要你十二周造出大型商业系统。我们先练会真实工作里最基本的闭环：说清要求 → 让工具执行 → 检查结果 → 出错能停下来。

参考答案只有四个数：共 5条，已完成 3条，待处理 2条，合计 60分钟。不需要商业知识，也没有真实客户资料。

下载学习材料

点击下载小白练习包

不知道下载后在哪里、什么是压缩包？没有关系，第1周从找下载文件、解压和双击打开开始教。现在先不用运行任何程序。

练习包里的代码是参考材料，不代表你已经写出了程序。课程会让你亲手改一点、验证一点；不要把别人的参考代码当独立开发经历。

按顺序开始

周 用日常语言说，这周学什么
第1周 找文件、解压、打开、保存
第2周 安装 DSH，认界面和工作文件夹
第3周 创建 API Key，接通模型
第4周 让 DSH 读写文件，并检查它动了哪里
第5周 认识终端和 Python，运行第一个程序
第6周 看报错、做检查、不盲信 AI
第7周 把成功步骤保存下来，下次照着做
第8周 认识 Skill、会话、Profile
第9周 不靠 DSH，直接试一次 API
第10周 注册 GitHub，用网页上传文件
第11周 发布一个不含秘密的静态网页
第12周 讲清作品、练习面试、制定后续计划

不理解时，怎么用办公助手？

WorkBuddy／千问办公二选一，能聊天就够了，不要求付费功能或本地文件权限。把下面这段发给它：

我是完全零基础，正在学习 DeepSeek Harness。
你只当辅导老师，不要一次给我完整技术方案。
请先解释我当前遇到的一个词，再给一个操作。
告诉我应该看到什么，等我回复后再继续。
不清楚我的界面时先问我，不编造按钮。
不要索要密码、API Key，也不要让我直接照抄危险命令。

如果它还是说得太难，补一句：请用教第一次用电脑的人的方式说，只告诉我下一步。

关于安全与真实结果

不要把密码或 API Key 发给任何聊天助手、同学、评论区；不上传到 GitHub。只在官方平台与软件对应的安全输入框里配置。不要让 DSH 看整个电脑、真实工作资料或私人文件。

本课程配套程序的离线检查已实际运行；你的 DSH 版本、菜单、模型列表与费用可能不同。我们没有替你注册账号或支付 API 费用，不能把示例答案当自己的成功记录。

十二周不是入职保证。先能自己完成一次，再逐渐补程序、测试、安全和真实业务经验；暂时不会代码并不妨碍开始。
